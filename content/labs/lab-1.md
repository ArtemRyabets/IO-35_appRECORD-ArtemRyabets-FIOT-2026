## 2. Опис предметного середовища

### 2.1 Короткий опис BlogPost Manager
BlogPost Manager — навчальний web-застосунок для роботи з блоговими публікаціями. Система передбачає перегляд списку постів, створення нових матеріалів, редагування вмісту та видалення застарілих записів.

### 2.2 Актуальність теми
Блогові платформи та внутрішні системи публікацій використовуються для ведення новин, навчальних матеріалів, технічних нотаток і документації. Для таких систем важливі зрозумілий інтерфейс, швидкий доступ до матеріалів і коректна робота на різних екранах.

### 2.3 Мета розробки
Метою розробки є створення базового інтерфейсу BlogPost Manager, який можна розширити серверною частиною, підключенням бази даних і повноцінними CRUD-операціями.

### 2.4 Завдання роботи
1. Описати предметну область BlogPost Manager.
2. Визначити об'єкт, предмет і бізнес-логіку.
3. Сформувати функціональні та нефункціональні вимоги.
4. Підготувати опис Use-case та ER-моделі.
5. Реалізувати адаптивну сторінку з header, main і footer.
6. Додати навігаційне меню та burger-menu для малих екранів.
7. Реалізувати адаптивну сітку карток блогових публікацій.
8. Додати hover-ефекти, transitions та просту анімацію появи карток.

### 2.5 Об'єкт і предмет
**Об'єкт:** процес керування блоговими публікаціями.

**Предмет:** frontend-інтерфейс web-застосунку BlogPost Manager для перегляду та навігації по блогових матеріалах.

## 3. Моделювання системи

### 3.1 Бізнес-логіка
Користувач відкриває застосунок, переглядає список публікацій і переходить до потрібного матеріалу. На наступних етапах система має підтримувати створення, редагування та видалення постів через REST API. Кожна публікація має назву, текст, автора та дату створення.

| FR-02 | Навігація | Перехід до розділів сторінки через меню. |
| FR-03 | Burger-menu | Відкриття і закриття мобільного меню. |

## 4. Хід виконання

### 4.1 Структура frontend-проєкту
```text
app/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── assets/
```

### 4.2 Реалізація header, main і footer
У файлі `index.html` створено семантичні блоки `header`, `main` і `footer`. Header містить логотип BlogPost Manager, навігаційне меню та кнопку burger-menu. Main містить hero-блок, картки публікацій, опис проєкту і блок можливостей. Footer містить контактну та довідкову інформацію.

### 4.3 Адаптивна сітка карток
Картки публікацій розміщено через CSS Grid. На desktop використовується три колонки, на tablet — дві, на mobile — одна.

```css
.posts-grid {
  display: grid;
  grid-template-columns: repeat(3, minmax(0, 1fr));
  gap: 1rem;
}
```

### 4.4 Burger-menu
Для малих екранів навігація приховується в burger-menu. JavaScript перемикає клас `is-open` і значення `aria-expanded`.

```js
burger?.addEventListener("click", () => {
  const isOpen = burger.classList.toggle("is-open");

  menu?.classList.toggle("is-open", isOpen);
  burger.setAttribute("aria-expanded", String(isOpen));
});
```

### 4.5 Media queries
У CSS додано media queries для tablet і mobile. Вони змінюють кількість колонок, поведінку меню, висоту hero-блоку та розташування footer.

### 4.6 Hover-ефекти та анімації
Для пунктів меню, кнопок і карток використано `transition`. Для карток додано анімацію плавного появлення через `@keyframes card-in`.

## 5. Висновки

Розроблено адаптивний frontend BlogPost Manager. Сторінка має header з логотипом і навігацією, mobile burger-menu, основний блок з картками блогових публікацій, опис проєкту та footer. Реалізовано адаптивну сітку, media queries, hover-ефекти й просту анімацію появи карток. Підготовлена структура може використовуватися для наступних лабораторних робіт, де додаються REST API та база даних.
